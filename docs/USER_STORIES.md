# User Stories

## 1. Track Job Applications

**As a user, I want to create and track my job applications, so that I can keep all my applications organized in one place.**

**Priority:** MVP

This is a core feature of the application and is necessary for the main purpose of the product.

---

## 2. Update Application Status

**As a user, I want to update the status of a job application, so that I can keep track of my progress throughout the hiring process.**

**Priority:** MVP

Status tracking is an essential part of managing job applications and provides a clear overview of where each application currently stands.

---

## 3. View Application Events

**As a user, I want to view the events related to a job application, so that I can keep track of important updates and activities throughout the hiring process.**

**Priority:** MVP

Events provide a history of what happened with an application and are important for maintaining useful context.

---

## 4. Search and Filter Applications

**As a user, I want to search and filter my job applications, so that I can quickly find specific applications without manually going through the entire list.**

**Priority:** MVP

As the number of applications grows, search and filtering become important for efficiently finding relevant information.

---

## 5. Receive Automatic Reminders

**As a user, I want to receive reminders about important follow-ups, so that I don't forget to contact employers or take action on an application.**

**Priority:** Post-MVP

This feature is not part of the current feature list. It could provide additional value, but it requires additional functionality such as scheduling, notifications, and reminder management. For the first version, I would prioritize the core application-tracking functionality and consider reminders for a future version.
